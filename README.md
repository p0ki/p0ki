## 🤖 What I'm Building

Most of my projects live at the intersection of **AI agents, automation, self-hosting, privacy, troubleshooting, and real-world workflows**.

### [x-bookmarks-mcp](https://github.com/p0ki/x-bookmarks-mcp)
A fully local, privacy-first MCP server that turns exported X/Twitter bookmarks into a searchable knowledge base for AI assistants.

**Built around:** Python · SQLite/FTS5 · MCP · async enrichment · Docker · local-first data handling

### [fitness-ai-agent](https://github.com/p0ki/fitness-ai-agent)
A private Dockerized Telegram fitness assistant with structured memory, meal/workout logging, summaries, photo analysis, backups, exports, and privacy/admin workflows.

**Built around:** Python · Telegram · SQLite · OpenAI · Docker · structured memory · privacy-first design

### Local Family Photos AI *(private project)*
A natural-language search layer for my self-hosted PhotoPrism library. It combines exact PhotoPrism filters with multilingual semantic search while keeping photos and personal metadata inside my private network.

**Built around:** PhotoPrism · Ollama · PostgreSQL/pgvector · n8n · embeddings · local AI

### DJ Viola / Poki Jukebox *(private project)*
A self-hosted two-room music controller operated through conversational commands. Deterministic playback logic handles the important actions, while a local LLM helps interpret less structured music requests.

**Built around:** Python · Matrix/Element · n8n · Ollama · MPV · Home Assistant / HEOS · Docker

### Avtoprem Platform & AI Automation *(private project)*
A full-stack automotive dealership platform with a public multilingual website, internal ERP/admin tooling, inventory and customer workflows, and an evolving AI/automation layer for operational assistance.

**Built around:** Laravel · Vue · PostgreSQL · Docker · n8n · AI-assisted development · workflow automation

### Triglav UM / Hermes *(private infrastructure)*
My always-on personal AI orchestration environment for experimenting with specialized agents, local tools, automation workflows, research, infrastructure support, and controlled access to my homelab services.

**Focus:** agent orchestration · tool/MCP integrations · local/private AI · n8n workflows · human approval boundaries

## 🧠 How I Work

I like systems that actually do something.

My usual workflow is:

**understand the problem → reproduce it → inspect logs/data → isolate variables → build a practical solution → test it → document it → automate the boring parts**

I use AI heavily for research, development, troubleshooting, and workflow design, but I treat model output as something to **verify**, not blindly trust.

A lot of my current work explores a pattern I strongly believe in:

> **Deterministic automation for reliable execution, AI agents for interpretation, planning, and flexible decision support.**

That means tools such as **n8n, APIs, databases, scripts, and explicit workflows** remain the reliable execution layer, while AI sits above them where reasoning or natural-language interaction is useful.
